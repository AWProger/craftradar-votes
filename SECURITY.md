# Security Policy / Безопасность

## Как сообщить об уязвимости

**Не открывайте публичный issue.** Используйте приватный канал:

1. GitHub → вкладка **Security** → **Report a vulnerability** (Private vulnerability reporting), или
2. e-mail: `denggy@yandex.ru`

Укажите: версию плагина, версию сервера/Java, шаги воспроизведения, ожидаемое и фактическое поведение. **Не присылайте** реальные `secret`, `config.yml` с секретом, логи с персональными данными игроков.

Сроки: подтверждение получения — до 3 рабочих дней, оценка — до 10 рабочих дней. Исправление выходит новым релизом; в описании релиза уязвимость упоминается после выхода исправления.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней минорной версии. Обновляйтесь до последнего релиза.

## Что считается уязвимостью

* обход подписи HMAC, утечка `secret` (в логи, команды, ответы, файлы вне `plugins/CraftRadarVotes/`);
* выполнение команд/подстановок, не заданных администратором в `config.yml`;
* выдача награды за диагностический пакет или подтверждение доставки, двойная выдача;
* запись файлов вне каталога плагина (path traversal в очереди/`requeue`).

Уязвимости сайта CraftRadar (`craftradar.ru`) сообщайте по тому же каналу — мы передадим их команде сайта.
